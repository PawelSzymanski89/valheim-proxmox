Address of the game server
Put a name here, not an address in numbers — on a home connection the number changes and a launcher built with it stops working. The launcher reads this at every start, so a change here reaches everyone without rebuilding anything.
While this is off, the launcher endpoints answer 404 — no manifest, no mod files, nothing. While it is on, they are open without a login, because a mod list is not a secret and the launcher has no account.
